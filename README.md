# Java DSA — Custom Data Structures Library

Hand-built implementations of core data structures in Java, with full JUnit 5 test coverage.

## Data Structures

| Structure | Package | Key Operations |
|---|---|---|
| HashMap (separate chaining) | com.dsa.map | put, get, remove, containsKey |
| Queue (linked list) | com.dsa.queue | enqueue, dequeue, peek |
| Stack (linked list) | com.dsa.stack | push, pop, peek |
| Singly Linked List | com.dsa.linkedlist.singly | add, remove, reverse |
| Doubly Linked List | com.dsa.linkedlist.doubly | bidirectional traversal |
| Circular Linked List | com.dsa.linkedlist.circular | circular traversal |

## Tech Stack
- Java 17
- JUnit 5
- Maven
